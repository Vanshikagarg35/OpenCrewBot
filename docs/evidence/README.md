# Evidence

Reports from each demo run go here.

Every run automatically saves its report to `data/reports/<runId>.md`. After running a
demo, copy that file here with a clear name, for example:

```
cp data/reports/run-ab12cd.md docs/evidence/demo1-market-intelligence.md
```

The reports in `data/reports/` from a mock mode run are not useful as evidence because the
agent text is placeholder. Run them again after adding a real API key.
