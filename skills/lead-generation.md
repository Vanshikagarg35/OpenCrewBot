# Lead Generation

- Define ideal customer profile first (who, where, size).
- Find public lists / directories (only public info, no personal phone numbers or private emails).
- For each lead: name of organisation, website, why they fit, public contact page.
- Suggest a first outreach message (draft only, don't send).
