# Presentation Creation

Make a slide outline:
- Slide 1: title + one line message
- 1 slide per main point, max 5 bullets per slide
- Last slide: next steps / ask

For each slide write: Title, Bullets, Speaker note (1-2 lines), Visual idea.
Keep 8-12 slides.
